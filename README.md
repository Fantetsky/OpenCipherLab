# OpenCipherLab

OpenCipherLab is an open-source research framework for analyzing classical and unsolved ciphers.

The project focuses on reproducible cryptanalysis experiments.

Current supported datasets:

- Zodiac Z13
- Zodiac Z32 (planned)
- Zodiac Z340 (planned)
- Generic substitution ciphers

This project does **not** claim to solve any unsolved cipher.
Its goal is to provide a transparent platform for testing hypotheses.
